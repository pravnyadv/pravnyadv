# Hi, I'm Praveen

Full stack engineer from India, nine years in. At work I build WhatsApp and HubSpot integrations and conversational AI. On the side I make tools that let Claude Code do more with less risk. I write at [pravn.dev](https://pravn.dev).

## Claude Code tools

- [safekeys](https://github.com/pravnyadv/claude-safekeys): type `$:NAME=value` and the key goes to your OS keychain. Claude only ever sees `$NAME`, and tool output is masked.
- [cpssh](https://github.com/pravnyadv/cpssh): copy a screenshot on your Mac, paste it into Claude Code running over SSH.
- [monday-claude](https://github.com/pravnyadv/monday-claude): a monday.com CLI and skill that also tracks which Claude session worked on which task and MR.
- [slack-claude](https://github.com/pravnyadv/slack-claude): read and reply on Slack as yourself, with every message drafted for your approval first.

The plugins install from one marketplace:

    /plugin marketplace add pravnyadv/claude-plugins
